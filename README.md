# RTerm（ccycide）

**让 Claude Code 始终运行在“可用区域”的机器上，你在任何地方用本地界面远程操作它。**

终端版 ToDesk：被控端装在服务器或可用区域内的电脑上，控制端凭“设备码 + 密码”接入，远程使用那台机器上的终端，重点优化 Claude Code 的远程使用体验。

## 要解决的问题

### 1. Claude 的风控

Claude 账号会受到网络环境和所在区域的风控：登录地、出口 IP、地区经常变化，账号就容易被限制甚至封禁。

RTerm 的做法是**不让 Claude Code 跑在你当前的网络里**：把它放在服务器，或所在区域可用的电脑上，登录和使用都发生在那台机器上，出口 IP 和地区始终稳定。你本地只是一个远程操作界面，不需要折腾本机的网络环境。

### 2. 现有远程终端做不到的事

SSH、远程桌面、各类网页终端用来跑 Claude Code 都有明显的短板：

| 现有远程终端 | RTerm |
|---|---|
| 每个按键都要网络往返才回显，打字不跟手，中文输入法更糟 | **输入无延迟**：输入框在本地，打字零延迟，回车后整条消息一次发送 |
| 无法粘贴图片和文件 | **支持粘贴、拖拽图片和文件**：自动上传到被控端，把路径交给 Claude Code |
| 切换模型、思考强度、权限模式、停止、压缩、清空等，只能记命令和快捷键 | **Claude Code 功能输入映射**：做成工具条按钮、菜单和命令面板，由被控端在终端里自动执行；显示工作状态，任务完成和需要确认时发通知 |
| 需要公网 IP、配置 SSH、端口映射 | 两端都主动连中继，输入设备码和密码即可 |
| 断线后会话丢失 | 被控端终端保活，重连后自动续传输出 |

## 主要特性

- 一个客户端同时具备主控和被控能力；另有无界面的命令行版（`rterm-cli`），适合 Linux 服务器做被控端
- **网页版**：浏览器里直接做主控端（端到端加密仍在浏览器里完成，服务端看不到明文），见 [docs/Web版.md](docs/Web版.md)
- 设备码（9 位数字）+ 密码（随机临时密码，也可设置固定密码）
- 端到端加密（SPAKE2 口令认证 + ChaCha20-Poly1305），服务端只转发密文，看不到终端内容和密码
- 远程终端多标签页，可一键启动 Claude Code，并带启动参数（模型、权限模式等）
- 本地输入框模式（默认）和直通模式（传统远程终端，适合 vim 等全屏程序）
- 断线自动重连，终端会话保活，输出按偏移续传，不丢不重
- 一台被控端最多同时接受 100 个控制端；**终端隔离开关**（默认开启，各控制端互相看不到对方的终端，可关闭），同一个终端被占用时其他人不能抢占
- 被控端可开启**连接确认**：有人请求连接时一直等你处理，不会超时自动拒绝
- 密码错误自动锁定、文件接收限制、连接提示和一键断开

## 工作方式

```
  你的电脑（任意网络）            中继服务              服务器 / 可用区域的电脑
  ┌──────────────┐         ┌────────────────┐         ┌──────────────────┐
  │ RTerm 控制端 │◄─加密─►│ 信令 + 中继    │◄─加密─►│ RTerm 被控端      │
  │ 本地输入框   │         │ 只转发密文     │         │ 终端 → Claude Code│
  └──────────────┘         └────────────────┘         └──────────────────┘
```

## 目录结构

| 路径 | 说明 |
|---|---|
| `proto/` | 协议定义（`rterm.proto`） |
| `crates/rterm-proto` | 协议编解码 |
| `crates/rterm-core` | 核心库：身份、信令、加密、PTY、会话、文件传输 |
| `crates/rterm-cli` | 命令行版（被控端） |
| `apps/desktop` | 桌面应用（Tauri 2 + Vite/React 前端） |
| `server` | 信令 / 中继 / 管理 API（Node.js + TypeScript） |
| `deploy` | Docker Compose、Caddy、备份脚本 |
| `scripts` | CI、发布、图标生成脚本 |
| `tools` | 运维脚本与早期验证 spike |
| `docs` | 验证结论、发布流程、安全审查报告 |

## 本地开发

```bash
# Rust 工作区
cargo build
cargo test

# 桌面应用
cd apps/desktop
npm ci
npm run tauri dev

# 服务端（内存存储，一键起信令 + 中继）
cd server
npm ci
npm run dev:all
npm test

# 本机一键跑全部检查
pwsh scripts/ci-local.ps1 -NoTest
```
