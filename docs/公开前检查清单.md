## 公开后的维护约定

- 不要把服务器 IP、域名、主机名、私钥路径、账号密码写进任何入库文件、提交信息、Issue、PR、CI 日志或镜像；需要时写占位符，并指向本机的 `docs/测试服务器凭据.local.md`。
- 凭据只放 `*.local.md` 或环境变量、CI 的 Secrets。
- `.env`、私钥、证书、抓包和日志不入库；新增 `.env.example` 时只写示例值。
- 第三方二进制不入库，写下载脚本并校验哈希。
- 提交前运行扫描（发现即非零退出）：

```
pwsh scripts/scan-secrets.ps1        # Windows（Windows PowerShell 也可用）
bash scripts/scan-secrets.sh         # Git Bash / Linux / macOS
bash scripts/scan-secrets.sh --history   # 同时扫整个 git 历史
```

  检查内容：公网 IPv4、私钥特征、常见 token 前缀、个人邮箱、本机用户名与路径、已知的测试服务器域名与主机名、密码片段、`.env`/密钥/二进制/大于 1MB 的文件；本机若有凭据文件，还会把其中的 IP 与密码当作精确值扫描。
- 一行版（粗略，仅供手动查）：`git grep -nIE '([0-9]{1,3}\.){3}[0-9]{1,3}|BEGIN [A-Z ]*PRIVATE KEY|gh[pous]_[A-Za-z0-9]{20,}|sk-[A-Za-z0-9]{20,}'`
- `docs/安全审查报告.md` 记录了漏洞的复现细节：每次公开发布前确认其“修复状态”里的高、中危都已修复，未修复的先改成不含复现细节的描述。

## 已决定的事项

- 开源许可证：**MIT**（根目录 `LICENSE`）。根 `Cargo.toml` 的 `[workspace.package]`（含 `repository`）、各 crate（`license.workspace = true`）与 `server/package.json` 已填 `MIT`；`apps/desktop/package.json` 与 `apps/desktop/src-tauri/Cargo.toml` 由前端侧负责，发布前确认一致。

## 仍需决定或确认

- 第三方依赖许可证检查（可重复运行）：
  - Rust：`cargo install cargo-deny`，在 `deny.toml` 里列出允许的许可证后运行 `cargo deny check licenses`；或 `cargo install cargo-license` 后运行 `cargo license`。
  - Node：在 `server/` 与 `apps/desktop/` 下运行 `npx license-checker --summary`（只要生产依赖用 `--production`）。
  - 目前的结果（本机用 `cargo metadata` 与 `node_modules` 做过一次）：没有 GPL / AGPL / LGPL。需要注意的有：Rust 侧 `cssparser`、`cssparser-macros`、`selectors`、`dtoa-short`、`option-ext`（MPL-2.0，文件级弱 copyleft，未修改地依赖即可，分发时保留其许可证声明）；`webpki-roots`（CDLA-Permissive-2.0）；`clipboard-win`、`error-code`、`windows-win`（BSL-1.0）；`icu_*`、`unicode-ident` 等（Unicode-3.0）。Node 侧 `lightningcss`（MPL-2.0，构建/测试工具）、`caniuse-lite`（CC-BY-4.0，构建工具的数据）。
  - 发布安装包时，需要随包附上第三方许可证清单（`cargo about` 或 `cargo-bundle-licenses` 可生成），以及微软 ConPTY 的许可证文本（MIT）。
- 是否加 `CODEOWNERS`、`CONTRIBUTING.md`、`SECURITY.md`（漏洞报告渠道，公开后建议至少加后者）：可选，待决定。
- `.github/workflows/` 里没有硬编码的服务器信息，使用的都是 `secrets.*` 与 `vars.*`；公开后注意 fork 的 PR 默认拿不到 Secrets。
- GitHub 上改为公开前：在仓库设置里确认没有遗留的 Deploy key、Webhook、Actions Secrets 里不该留的值。
